## Ozon

Исходный товар5892688031 закончился; пользователь выбрал восстановленный
iPhone14Pro256ГБ3927100392. Share-параметры at/sh не нужны для идентичности
товара и не предлагаются для постоянного page URL.

Первый экспорт был HTML-запросом без Cookie. Гостевой context только с UA/
client hints не получил цену (RPC deadline). Затем пользователь предоставил
first-party JSON API POST с пустым body к entrypoint route. Команда не

к hostname; проверка нового товара выполнялась отдельным **GET** с правильным
product URL. HTTP_JSON на entrypoint route вернул403/SESSION_REJECTED.

проверка canonical/title нового товара завершилась UPSTREAM_TIMEOUT.

**удаление старой локальной истории**. Условия сохраняются: у13/19 обычная

нужно сбросить, generation повысить, старые результаты отклонить.
