# Начальная схема

Миграция 1 создаёт схему сервиса мониторинга. Миграция 2 создаёт начального администратора из `ADMIN_EMAIL` и `ADMIN_PASSWORD` и служебные записи планировщика. Применяйте их к новой пустой базе.

Прежняя история миграций несовместима с этой серией: существующую базу нужно пересоздать. Не изменяйте вручную версию в `schema_migrations`.
