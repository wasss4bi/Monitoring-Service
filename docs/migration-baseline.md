# Начальная схема

Миграция 1 создаёт схему сервиса мониторинга. Миграция 2 создаёт начального администратора из `ADMIN_EMAIL` и `ADMIN_PASSWORD` и служебные записи планировщика. Новые миграции добавляются в тот же каталог с последовательно возрастающими номерами.

При каждом запуске применяются только ещё не выполненные миграции. Состояние хранится в `schema_migrations`. При ошибке миграции состояние может стать `dirty`: сначала изучите фактическое состояние базы и причину ошибки, затем восстановите согласованность. Не меняйте версию вручную без проверки.
